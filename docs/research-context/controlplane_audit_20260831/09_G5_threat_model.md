# G. G5 — threat-model assessment

**Headline: the repository contains no threat model, no adversarial evaluation, and no attacker-capability definition.** `docs/ROADMAP.md` §6 plans an "Adversarial / chaos" test tier ("kill the DB mid-decision, return stale evidence, time out the grounding model, corrupt a receipt") and calls chaos-testing the verifier *"the one test worth naming in the README"*. **It is not implemented.** No file in any commit performs it.

Below, each threat is traced to the exact code that would have to hold.

|---|---|---|---|---|---|---|
| T-1 | **Agent proposes a wrong tool call** | agent can choose tool + arguments | claims resolved against fresh record; predicates; verdict + intervention | `intercept.py::_run_gate`, `decide.py::decide` | **YES** (unit + one scenario) | Only for the 2 modelled tools; `build_claims` raises for any other tool — a **fail-loud** design, correctly chosen |

## Summary

| Class | Count |
|---|---|
| Defended **and** tested end-to-end | 2 (T-1 partial, T-12) |
| Defended in code, **untested** | 4 (T-5 unit-only, T-7 partial, T-16, T-8) |
| **Confirmed fail-open** | 2 (**T-3**, **T-4**) |
| Mechanism present but **dead / unwired** | 4 (T-8, T-9, T-11, plus `fail_posture` in T-6) |
| **No defence** | 5 (T-2, T-6, T-13, T-15, T-17) |

**T-3 is the most serious finding in this file and one of the two most serious in the audit.** It is a silent fail-open on the exact use case built to demonstrate that detection alone is insufficient: under `knowledge_assistant.yaml`, an `UNVERIFIABLE` verdict maps to `allow_with_caveat` → `MODIFY` → `impl(**(None or args))` → **the document is sent unchanged**. Fixing it is a few lines (either populate `modified_args`, or make `MODIFY` unreachable until a modifier exists, or raise on `MODIFY` with no `modified_args`). It requires no experiment.

**Wording that is safe today:** *"ControlPlane has no threat model and no adversarial evaluation. The mechanism is designed for a non-adversarial failure mode — a correct agent acting on stale or misresolved context. Behaviour under a hostile agent, a hostile caller, or an unavailable store is unspecified and untested."* Contrast OAP (2603.20953), which reports 879 adversarial attempts against a live bounty testbed.
